# Trasteros NIDOX · Hitos (web pública cifrada)

Este repositorio solo contiene la web de seguimiento de hitos de Trasteros NIDOX, **cifrada con contraseña** (StatiCrypt), para publicarla con GitHub Pages.

- **Dirección:** https://planabyt.github.io/trasteros-hitos/
- **Contraseña:** la da el responsable del proyecto. No está guardada en ningún repositorio.
- **No editar aquí.** La fuente está en el repositorio privado `planabyt/trasterosnidox`. Se publica con `TRASTEROS_NIDOX_PASSWORD='…' bash web/publicar_web.sh` desde ese repositorio.
- `.staticrypt.json` contiene la "sal" del cifrado (no es secreta). Mantenerla hace que la opción "Recordarme" siga funcionando tras cada actualización.
